## Goal

Implement the framework-free geometry primitives that every other domain lib, the renderer, and (later) the precision-guide overlays depend on.

## Spec reference

Plan Stage 0 F0.2; `aqua-document.ts` `Vec2` / `Vec3` / `Transform` types.

## Dependencies

**Requires:** F0.1.
**Enables:** F0.3 (scene-model uses geometry), F0.4 (renderer uses hit-test + transforms), F5.3 (golden-ratio overlays).

## Scope

**In, in `libs/domain/geometry/`:**

- `Vec2` and `Vec3` primitive operations: `add`, `sub`, `mul`, `scale`, `dot`, `cross` (3D), `length`, `normalize`, `distance`, `lerp`. Pure functions over plain `{x, y}` / `{x, y, z}` objects matching the shapes in `aqua-document.ts`.
- `Transform` ops: compose two transforms, invert a transform, apply a transform to a `Vec3`. Match the `Transform` shape from the document (position/rotation radians/scale/flipX/flipY).
- **Projection:** `project2D(v: Vec3): Vec2` — projects along −z to give the 2D renderer its view (per `aqua-document.ts` design rule 2).
- AABB primitives: `aabbContainsPoint`, `aabbIntersects`, `aabbFromPoints`, `aabbExpand`.
- Hit-test primitives: `pointInRect`, `pointInRotatedRect`, `pointInCircle`, `pointInPolygon` (even-odd rule).
- Composition helpers: `transformAabb(aabb, transform)` so hit-test against a rotated/scaled object's AABB is one call.
- Golden-ratio / rule-of-thirds helpers used in Stage 5:
  - `goldenRatioLines(width, height): { vertical: number[]; horizontal: number[] }`
  - `thirdsLines(width, height): { vertical: number[]; horizontal: number[] }`
  - `focalPoints(width, height): Vec2[]` — the four classic golden-ratio focal points.
- Snap helpers: `snapToGrid(p: Vec2, gridSize: number): Vec2`, `snapToValue(v: number, snaps: number[], tolerance: number): number`.

**Out:**

- Bezier / spline curves for substrate profiles → F2.2.
- 3D mesh hit-testing → F10.1.
- Random / seeded helpers → live in `domain/growth-sim`.

## Acceptance criteria

- [ ] Lib has tag `scope:domain` and zero non-domain dependencies.
- [ ] No Angular, DOM, Electron, NgRx, or RxJS imports.
- [ ] Public API exported via `index.ts`.
- [ ] All functions are pure (same inputs → same outputs, no side effects).
- [ ] Operates on plain objects matching `aqua-document.ts` shapes — no class instances.
- [ ] Test coverage ≥90%.

## Testing

- **Unit:** every public function with table-driven cases. Include edge cases: zero-length vector normalize, identity transform, degenerate AABB (zero width/height), point exactly on rect boundary.
- **Property tests** (fast-check or similar):
  - `compose(t, identity) ≡ t`
  - `compose(t, invert(t)) ≡ identity` (within float tolerance)
  - `project2D` is a left-inverse for any `Vec3` with `z = 0`
  - `aabbContainsPoint(aabbFromPoints(ps), p)` is true for any `p ∈ ps`
- **Component / E2E:** none (pure library).

## Notes

- **Float tolerance.** Adopt a single `EPSILON = 1e-6` constant and use it consistently across comparisons. Document it.
- **Right-handed coords reminder.** `+x` right, `+y` up, `+z` back. Rotation positive direction follows the right-hand rule. Cross products and rotation conventions must agree with this — write tests that exercise direction explicitly.
- **mm units, not pixels.** Geometry math operates on mm. Pixel conversion is a renderer concern.
