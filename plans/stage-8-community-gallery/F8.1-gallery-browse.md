# F8.1 — Gallery browse

**Stage:** 8 — Community Gallery
**Owner:** `angular-feature-engineer`
**Collaborators:** `electron-platform-engineer` (capability flag), `test-engineer`
**Status:** Not started

## Goal

Browse community-published layouts with thumbnail, planting plan, fish list, and gear visible per tank. Optional / online-only — gracefully absent when offline or in self-hosted-less mode.

## Spec reference

Plan Stage 8 F8.1.

## Dependencies

**Requires:** F8.3 (backend contract).
**Enables:** F8.2 (publish/import).

## Scope

**In:**

- `features/templates/` or a new `features/gallery/`: paginated grid of community layouts.
- Each card: thumbnail, title, author, summary (plant count, livestock count, tank size).
- Filters: tank size range, style tag (Iwagumi / Dutch / nature / …), difficulty.
- Capability gating: if `platform-api.GalleryService.isAvailable()` returns false (offline / no backend configured), the gallery menu entry is hidden cleanly.
- Detail view: full layout card with everything, plus "Open as remix" button.

**Out:**

- Comments / likes / social features — out of v1 scope.

## Acceptance criteria

- [ ] Capability flag hides the menu when unavailable.
- [ ] Pagination + filters work against a mock backend.
- [ ] Detail view shows every section.
- [ ] Network failure surfaces a clean retry, not a crash.

## Testing

- **Unit:** capability gating logic.
- **Component:** grid + detail rendering.
- **E2E:** with a mock server, browse and view a detail.

## Notes

- **Strictly optional.** The desktop offline build hides this behind a capability flag (per plan §8). It must boot and function without any network.
- **Backend agnostic.** Front-end depends on the `GalleryService` interface; the backend impl is configurable.
