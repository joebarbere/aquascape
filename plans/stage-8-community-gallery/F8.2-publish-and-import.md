# F8.2 — Publish & import (remix)

**Stage:** 8 — Community Gallery
**Owner:** `angular-feature-engineer`
**Collaborators:** `aqua-document-guardian` (attribution metadata), `test-engineer`
**Status:** Not started

## Goal

Publish a layout to the gallery (thumbnail + `.aqua`) and import others' layouts to remix locally.

## Spec reference

Plan Stage 8 F8.2.

## Dependencies

**Requires:** F8.1 (gallery exists), F8.3 (backend contract).
**Enables:** Social discovery — completes Stage 8.

## Scope

**In:**

- Publish flow:
  - User fills out title, description, style tags.
  - Auto-generate a thumbnail (render the scape via F6.1 at 800×600).
  - Upload `.aqua` + thumbnail to the backend via `GalleryService.publish`.
  - Show success / failure clearly.
- Import flow:
  - "Open as remix" from a detail page downloads the `.aqua`, creates an untitled local copy with attribution metadata preserved in `meta.remixedFrom = { author, title, galleryId, fetchedAt }`.
  - Don't overwrite the user's current doc — open the remix in a new editor session (or prompt to save).
- Attribution metadata schema additions (coordinate with `aqua-document-guardian`):
  - `meta.author` (already in v1).
  - Optional `meta.remixedFrom` chain — preserved across multiple remixes.

**Out:**

- Auth flow / account creation — backend's job; the front-end consumes a token via the platform layer.

## Acceptance criteria

- [ ] Publish posts the document + thumbnail to the configured backend.
- [ ] Failed publishes surface a retryable error.
- [ ] Imported layouts include attribution metadata that round-trips.
- [ ] Sensitive info (anything resembling secrets in document `meta`) is never accidentally posted — sanitize before upload.

## Testing

- **Unit:** attribution chain handling; sanitization rules.
- **Component:** publish form validation.
- **E2E:** publish to mock server, browse, import as remix, save — attribution preserved.

## Notes

- **No PII leakage.** The document `meta.author` field is user-supplied; the publish form should let the user override or anonymize. Don't auto-fill with OS user name.
- **Remix chain length.** Cap at a sensible depth (e.g. 10) to avoid unbounded chains; older entries can be summarized.
