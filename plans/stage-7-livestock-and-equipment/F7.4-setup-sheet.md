# F7.4 — Setup sheet (combined export)

**Stage:** 7 — Livestock & Equipment
**Owner:** `angular-feature-engineer`
**Collaborators:** `catalog-engineer`, `test-engineer`
**Status:** Not started

## Goal

Generate a combined "setup sheet" with the layout summary (F6.2) plus livestock and equipment sections — the comprehensive plan someone would walk into a fish store with.

## Spec reference

Plan Stage 7 F7.4.

## Dependencies

**Requires:** F6.2 (layout summary), F7.1–F7.3 (livestock + equipment data).
**Enables:** A genuinely useful real-world artifact for v1.x users.

## Scope

**In:**

- Extend `LayoutSummary` aggregator with `livestock` and `equipment` sections.
- New formats: PDF + printable HTML.
- UI: "Export setup sheet" — picks format + sections to include (everything by default).
- Sections produced:
  - Tank specs.
  - Substrate breakdown + estimated bag quantities.
  - Plant list grouped by zone with light/CO2/difficulty.
  - Hardscape list with category + count.
  - Livestock with counts + suggested water parameters.
  - Equipment with brand/model + notes.
  - Suggested params (combined from F6.2 + livestock requirements).
  - Compatibility warnings (if any) — included with a clear "Advisory" header.

**Out:**

- Shopping-link generation — out of scope.

## Acceptance criteria

- [ ] Setup sheet contains every section listed above.
- [ ] PDF is well-formatted at A4 / Letter sizes.
- [ ] Compatibility warnings are clearly marked as advisory.
- [ ] Aggregator is pure and testable.

## Testing

- **Unit:** aggregation tested against fixture scenes.
- **Snapshot:** HTML output matches reference for a fixture scene.
- **E2E:** generate setup sheet, open the file, contains every expected section.

## Notes

- **Single source of truth.** The aggregator is one function; PDF / HTML / Markdown are different renderers of the same structure. Don't reimplement aggregation per format.
- **Print CSS.** If using HTML→PDF, page breaks and printable sizes need explicit attention.
