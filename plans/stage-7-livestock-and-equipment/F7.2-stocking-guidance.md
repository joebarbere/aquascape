# F7.2 — Stocking guidance (compatibility + bioload)

**Stage:** 7 — Livestock & Equipment
**Owner:** `angular-feature-engineer`
**Collaborators:** `catalog-engineer`, `test-engineer`
**Status:** Not started

## Goal

Advisory warnings for incompatible species and rough bioload vs. tank volume — rule-based and explainable.

## Spec reference

Plan Stage 7 F7.2.

## Dependencies

**Requires:** F7.1, F6.2 (volume calc).
**Enables:** F7.4.

## Scope

**In:**

- Compatibility matrix in `domain/catalog/`: a deterministic rule set evaluating pairs of species → `{ ok: boolean; reason?: string }`. Rules consider:
  - Temperament mismatches (predatory + small).
  - Temp/pH range overlap.
  - Schooling minimum unmet.
  - Fin-nipper + long-fin species.
- Bioload check: sum `bioloadCoefficient × count` ≤ `tankVolumeL × maxBioloadPerL`. Surface percentage and threshold warnings.
- UI: warnings panel listing each issue with the offending species pair and the rule that fired.
- Warnings are **advisory** — never block placement. Per plan §7.

**Out:**

- Real-time prediction of disease, breeding, water chemistry — out of scope.

## Acceptance criteria

- [ ] Each rule has at least one test fixture exercising a known true and a known false case.
- [ ] Warnings explain themselves: each surfaced warning includes the rule name + the inputs that triggered it.
- [ ] Placing incompatible species produces a warning, not a block.

## Testing

- **Unit:** every rule. Bioload math.
- **Component:** warnings panel updates as livestock change.
- **E2E:** add incompatible fish → warning appears with the explanation.

## Notes

- **Conservatism.** When sources disagree, surface the warning. Better to over-warn than to mislead a beginner into a deadly mix.
- **Don't pretend it's prescriptive.** UI copy: "Compatibility check (advisory)" with a "Why?" affordance.
