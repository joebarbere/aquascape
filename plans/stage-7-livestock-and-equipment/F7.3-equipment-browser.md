# F7.3 — Equipment browser

**Stage:** 7 — Livestock & Equipment
**Owner:** `catalog-engineer`
**Collaborators:** `angular-feature-engineer`, `test-engineer`
**Status:** Not started

## Goal

Add filters / heaters / lights / CO2 systems to a design with searchable / filterable browser. Attach equipment to the design with optional notes.

## Spec reference

Plan Stage 7 F7.3.

## Dependencies

**Requires:** F2.4 (catalog loader).
**Enables:** F7.4 (setup sheet).

## Scope

**In:**

- `EquipmentCatalogEntry`:
  - `id`, `version`, name, brand.
  - `kind`: `'filter' | 'heater' | 'light' | 'co2' | 'pump' | 'chiller'`.
  - Spec metadata varying by kind:
    - filter: flow rate L/h, recommended tank L range.
    - heater: watts, recommended tank L range.
    - light: PAR / lumens, color temp K, recommended tank dimensions, suitable plant light tier.
    - co2: type (pressurized / liquid / DIY), bps capacity.
  - `thumbnailRef`, `productUrl?` (optional manufacturer link).
- `EquipmentAttachment` in the scene (not necessarily a `SceneObject` since it's not drawn in the scape itself):
  - Lives in `scene.equipment[]` (additive schema field — coordinate with `aqua-document-guardian`).
  - Carries `catalogRef`, optional `notes`, `quantity`.
- `features/livestock-equipment/` browser with kind tabs + filters + search.

**Out:**

- Equipment rendered in the scene visually — out for v1; equipment is metadata, not scape geometry.

## Acceptance criteria

- [ ] At least 30 equipment entries across all kinds.
- [ ] Browser filters by kind + spec ranges (e.g. "filters rated for 100–250 L").
- [ ] Attachment persists and round-trips.
- [ ] Notes field accepts plain text with reasonable length cap (e.g. 500 chars).

## Testing

- **Unit:** schema validation; filter logic.
- **Component:** browser tabs + filters.
- **E2E:** attach equipment, save, reopen — preserved.

## Notes

- **Add to the schema cleanly.** `scene.equipment` is an additive field; older readers preserve it via the forward-compat rule.
- **Brand fairness.** Cover popular brands (Eheim, Fluval, Chihiros, Twinstar, …) plus generic options. Don't show favoritism.
