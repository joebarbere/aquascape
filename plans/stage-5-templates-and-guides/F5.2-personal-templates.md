# F5.2 — Personal templates

**Stage:** 5 — Templates & Precision Guides
**Owner:** `angular-feature-engineer`
**Collaborators:** `electron-platform-engineer` (storage location), `test-engineer`
**Status:** Not started

## Goal

Let users save a layout as a personal template and re-instantiate it later.

## Spec reference

Plan Stage 5 F5.2.

## Dependencies

**Requires:** F5.1 (template mechanism).
**Enables:** Personal workflow speedups.

## Scope

**In:**

- "Save as template…" menu entry — prompts for name + description; writes a `.aqua` file with `meta.isTemplate: true` to a user templates directory.
  - Web: IndexedDB or File System Access folder of the user's choosing.
  - Electron: `userData/templates/`.
- Personal templates appear in the template browser (F5.1) under a "My templates" tab.
- Delete + rename personal templates.

**Out:**

- Sharing personal templates to a community — Stage 8.

## Acceptance criteria

- [ ] Save-as-template writes a valid `.aqua` file with `isTemplate: true` and the user-provided name.
- [ ] Personal templates appear in the browser and load correctly.
- [ ] Delete prompts for confirmation.
- [ ] Personal templates round-trip identically (no fields stripped).

## Testing

- **Unit:** template path resolution; name → filename sanitization.
- **E2E:** save layout as template, restart app, load from browser, verify identical.

## Notes

- **Filename sanitization.** Strip path separators, control chars, reserved Windows names (CON, PRN, …). Test with quirky inputs.
- **Storage backends.** Reuse `StorageService` patterns from F1.5 rather than inventing a new IO path.
