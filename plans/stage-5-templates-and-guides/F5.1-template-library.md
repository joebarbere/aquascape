# F5.1 — Template library

**Stage:** 5 — Templates & Precision Guides
**Owner:** `angular-feature-engineer`
**Collaborators:** `aqua-document-guardian`, `catalog-engineer`, `test-engineer`
**Status:** Not started

## Goal

Ship a library of starter layouts (Iwagumi, Dutch, jungle, beginner-friendly) that the user can load and immediately edit.

## Spec reference

Plan Stage 5 F5.1.

## Dependencies

**Requires:** F1.3 (templates are `.aqua` documents), F1.4 (loading), F4.x (plants exist for the planted templates).
**Enables:** F5.2 (personal templates reuse the mechanism).

## Scope

**In:**

- Template documents are normal `.aqua` files with `meta.isTemplate: true` (already in `aqua-document.ts`).
- Ship at least 6 starter templates as part of the app bundle:
  - Iwagumi (three-stone, 60-P).
  - Dutch (terraced midground, 90-P).
  - Jungle (dense, mixed, 60 cm cube).
  - Nature-style (driftwood focal, 90-P).
  - Beginner low-light (90 cm planted, easy plants only).
  - Minimal (rimless cube with one rock).
- `features/templates/` UI:
  - Template browser modal accessible from New / File menu.
  - Thumbnail + title + description for each.
- "Load template" creates an untitled, editable copy in the document store (does not modify the bundled template file).

**Out:**

- User-created templates — F5.2.
- Network / community templates — Stage 8 (gallery overlap).

## Acceptance criteria

- [ ] Templates validate against the v1 schema (F1.3 round-trip test covers them).
- [ ] Loading a template creates an untitled doc with `isTemplate: false` in the copy.
- [ ] Original template file is never modified.
- [ ] Template browser is keyboard navigable.

## Testing

- **Unit:** load-template logic clears `isTemplate` and `meta.id` (assigns a new UUID).
- **Component:** browser renders and filters.
- **E2E:** load a template, customize, save (under a new name), verify the bundled template is unchanged.

## Notes

- **Templates are real documents.** Don't invent a separate format. The `isTemplate: true` flag is the only distinguishing field.
- **Curation.** Quality of starter templates is a marketing surface — they're often the first thing a new user sees. Get them right.
