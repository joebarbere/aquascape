# F4.1 — Plant placement

**Stage:** 4 — Layers & Planting Tool
**Owner:** `angular-feature-engineer`
**Collaborators:** `catalog-engineer`, `scene-model-engineer`, `renderer-engineer`, `test-engineer`
**Status:** Not started

## Goal

Place individual plants from a categorized plant catalog with placement-zone metadata (foreground / midground / background), lighting / CO2 / difficulty info, and the same drag-and-drop UX as hardscape.

## Spec reference

Plan Stage 4 F4.1.

## Dependencies

**Requires:** F2.4 (catalog loader), F3.1 (DnD palette pattern), F4.2 (layers concept).
**Enables:** F4.3, F4.4, F4.5.

## Scope

**In:**

- Plant catalog schema (`catalog-engineer`):
  - `id`, `version`, display name, scientific name.
  - `zone: 'foreground' | 'midground' | 'background' | 'epiphyte' | 'floating'`.
  - Light requirement: `'low' | 'medium' | 'high'`.
  - CO2: `'optional' | 'recommended' | 'required'`.
  - Difficulty: `'easy' | 'medium' | 'hard'`.
  - Growth params (consumed by F4.4): `initialHeight`, `matureHeight`, `initialSpread`, `matureSpread` (all mm), `maturityWeeks`, `growthCurve: 'linear' | 'sigmoid' | 'sqrt'`.
  - Visual: silhouette outline or leaf primitive descriptor, base color, leaf-shape token.
  - `thumbnailRef`.
- Core plant catalog with at least 20 well-known species across all zones.
- `features/planting-tool/` palette UI (similar to F3.1):
  - Zone tabs, light/CO2/difficulty filter chips, search.
  - Inspector panel showing plant metadata for the selected catalog entry.
- Placement via DnD onto the canvas: dispatches `AddObject` with a `PlantObject`.
- A default "Plants" layer is created if none exists.

**Out:**

- Brush / scatter placement — F4.5.
- "Grow into each other" blending — F4.3.
- Time-slider growth simulation — F4.4.

## Acceptance criteria

- [ ] Plant placement works end-to-end with the same DnD UX as hardscape.
- [ ] Inspector shows light / CO2 / difficulty / zone metadata.
- [ ] Zone filter narrows the catalog correctly.
- [ ] Schema validation enforces growth-param consistency (e.g. `matureHeight >= initialHeight`).

## Testing

- **Unit:** plant catalog validation; growth-param invariants.
- **Component:** palette filter; inspector renders all metadata.
- **E2E:** place plants, save, reopen — identical.

## Notes

- **Provenance again.** Plant params from reputable sources where possible (Tropica, Dennerle, the Aquascape Wiki). Where uncertain, mark approximate.
- **Visual rendering of plants** can be simple at this stage — colored silhouettes / leaf shapes. The renderer will get richer over time.
