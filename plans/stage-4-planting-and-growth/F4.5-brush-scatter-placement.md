# F4.5 — Brush / scatter placement for carpets

**Stage:** 4 — Layers & Planting Tool
**Owner:** `angular-feature-engineer`
**Collaborators:** `growth-sim-engineer` (seeded scatter algorithm), `scene-model-engineer` (CompositeCommand), `test-engineer`
**Status:** Not started

## Goal

Paint many plants at once with a brush tool — essential for foreground carpets (HC Cuba, Monte Carlo, dwarf hairgrass) where placing individuals one-by-one is tedious.

## Spec reference

Plan Stage 4 F4.5.

## Dependencies

**Requires:** F4.1 (plant placement), F4.4 (seeded scatter algorithm lives in growth-sim), F2.2 (substrate profile — brush respects substrate height).
**Enables:** Carpeting workflows central to Iwagumi and Dutch styles.

## Scope

**In, in `domain/growth-sim/`:**

- `scatterPlants(args): PlantPlacement[]` — pure, seeded:
  ```ts
  function scatterPlants(args: {
    plantId: CatalogRef;
    region: Polygon; // brush footprint in world mm
    density: number; // plants per cm² (mm² internally)
    jitter: number; // 0..1, position randomness within Poisson disk
    seed: number;
  }): { transform: Transform; instanceSeed: number }[];
  ```
  Algorithm: Poisson-disk sampling with jitter, deterministic from seed. Same seed + same region + same density = same placements.

**In, in `features/planting-tool/`:**

- Brush tool UI: brush size, density slider, jitter slider, plant picker.
- On a brush stroke (mouse / touch drag): accumulate the swept polygon, debounce into a `ScatterPlants` action; on stroke end, dispatch a `CompositeCommand([...AddObject])` so the entire stroke is one undo step.
- Live preview: while painting, show ghost placements at the current stroke's accumulated region.

**Out:**

- "Eraser brush" — defer to a later polish pass; for now, lasso-select + delete works.
- Plant-density variation along stroke ("airbrush" feel) — out of scope.

## Acceptance criteria

- [ ] Scatter is reproducible: same seed + region + density → identical placements (property-tested).
- [ ] A brush stroke produces one undo step regardless of how long the stroke is.
- [ ] Live preview matches the final placement (no jump on stroke end).
- [ ] Substrate height is respected: scattered plants sit on the substrate profile, not floating above the tank floor.
- [ ] Performance: a 500-plant brush stroke completes in <250 ms.

## Testing

- **Unit:** Poisson-disk sampling correctness; density math; seed reproducibility.
- **Property:** seeded reproducibility across platforms.
- **Component:** brush stroke produces a CompositeCommand with the expected number of children.
- **E2E:** paint a carpet → save → reopen → identical placements.

## Notes

- **Seeding.** The document's master `seed` is the parent; per-stroke sub-seed derives from `hash(docSeed, strokeIndex)`; each plant's `instanceSeed` derives from `hash(strokeSeed, plantIndex)`. Persist `strokeSeed` per stroke so re-replaying produces identical placements even if the stroke index counter is reset.
- **Substrate-aware placement.** The brush samples the substrate profile at each placed plant's `x` to compute `y`. If the substrate has multi-region profiles (F2.3), use the appropriate region.
- **Don't store the rendered placements as raw scatter results.** Each scattered plant becomes a real `PlantObject` in the scene — that's what makes them individually editable and undoable.
