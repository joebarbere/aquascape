# F4.2 — Layers panel

**Stage:** 4 — Layers & Planting Tool
**Owner:** `angular-feature-engineer`
**Collaborators:** `scene-model-engineer`, `test-engineer`
**Status:** Not started

## Goal

A familiar Photoshop-style layers panel: create / rename / reorder / set opacity / lock / hide layers. Layer order is draw order.

## Spec reference

Plan Stage 4 F4.2.

## Dependencies

**Requires:** F0.3 (Layer + layer commands).
**Enables:** F4.3 (grouping is a layer concept), all later tools (every editor relies on layer ordering and locking).

## Scope

**In, in `features/layers-panel/`:**

- Layer list:
  - Drag-to-reorder using Angular CDK DragDrop.
  - Rename inline.
  - Opacity slider per layer.
  - Lock toggle (locked layers reject edit commands).
  - Visibility toggle (hidden layers skip render and skip hit-test).
  - Layer count indicator (e.g. "5 objects").
- New / delete layer buttons.
- Active-layer indicator — new placements drop into the active layer by default.
- All actions dispatch the corresponding commands from F0.3 (`AddLayer`, `RemoveLayer`, `RenameLayer`, `SetLayerOpacity`, `SetLayerVisibility`, `SetLayerLocked`, `ReorderLayers`).
- Multi-select layers (Shift-click) for bulk operations.
- Move-to-layer command: `MoveObjectsToLayer(objectIds, targetLayerId)`.

**Out:**

- Layer "blend modes" (multiply, screen) — out of scope for an aquascape app.
- Sublayers / nested groups — F4.3 grouping is intra-layer, not sub-layer.

## Acceptance criteria

- [ ] Reorder, rename, opacity, lock, visibility all functional and undoable.
- [ ] Locked layer rejects placement, transform, delete with a typed `EditRejected` outcome surfaced as a discreet toast.
- [ ] Hidden layers are not rendered and not hit-tested.
- [ ] Renaming with empty string falls back to "Untitled layer".
- [ ] Panel is fully keyboard navigable; layer-list items announce their state to screen readers.

## Testing

- **Unit:** layer commands' apply/invert (already covered in F0.3); locked-layer rejection.
- **Component:** drag reorder dispatches the right command; opacity slider debounces.
- **E2E:** reorder layers, save, reopen — order preserved.

## Notes

- **Opacity semantics.** Layer opacity multiplies with per-object opacity. Document the rule clearly.
- **Initial state.** Documents always have at least one layer ("Default"). Deleting the last layer is rejected.
