# F3.5 — Hardscape catalog

**Stage:** 3 — Hardscape Tool
**Owner:** `catalog-engineer`
**Collaborators:** `renderer-engineer`, `test-engineer`
**Status:** Not started

## Goal

Build out the hardscape catalog: rocks (Seiryu, Ryuoh, Dragon Stone, Frodo Stone, lava, plus generics) and driftwood (spiderwood, manzanita, malaysian, mopani, plus generics) with 2D outline geometry and thumbnails.

## Spec reference

Plan Stage 3 F3.5.

## Dependencies

**Requires:** F2.4 (catalog loader).
**Enables:** F3.1 (palette has entries to drag).

## Scope

**In:**

- `HardscapeCatalogEntry` type and schema, with fields:
  - `id`, `version`, display name.
  - `kind: 'rock' | 'driftwood'`.
  - `category` — e.g. `'seiryu'`, `'spiderwood'`.
  - `outline: Vec2[]` — 2D polygon outline in local mm coordinates, centered on the local origin.
  - `thumbnailRef` — path to a thumbnail PNG (loaded via the catalog asset helper from F2.4).
  - `defaultColor: HexColor` — fallback if no texture is provided.
  - `texture?: { id: string; tileable: boolean }` — optional texture token (matches the substrate texture token pattern from F2.1).
  - Optional `meshRef` (3D mesh) — empty for now; F10.3 fills these in.
- A starter core hardscape catalog with ~15 rocks and ~10 driftwood entries.
- Renderer extension: draw a `HardscapeObject` by filling its outline polygon (in object-local coords transformed into world coords), applying texture if present, otherwise default color.

**Out:**

- 3D meshes — F10.3.
- Generated variations (procedural rocks) — out of scope.

## Acceptance criteria

- [ ] At least 25 hardscape entries shipped with believable outline geometry.
- [ ] All entries validate against the schema.
- [ ] Renderer correctly draws every entry given a default transform.
- [ ] Outlines are convex-ish enough that drag-and-drop hit-testing feels right; document any pathological outlines that don't hit-test cleanly and either fix them or simplify the renderer's hit logic.

## Testing

- **Unit:** schema validation per entry; outline winding (consistent CCW, say).
- **Snapshot test:** render each entry at default transform to a small bitmap and snapshot-compare.

## Notes

- **Outline sourcing.** Hand-drawn 2D outlines are fine for v1. Aim for distinctive silhouettes that read at thumbnail size.
- **Naming.** Use the well-known names where they're product names (e.g. "ADA Seiryu Stone"). For generics, prefer descriptive names ("Layered grey rock") over confusing trademark-adjacent labels.
- **Licensing.** Outlines and thumbnails must be original or CC0; don't trace product photos.
