# F3.3 — Transform handles + mirror/flip

**Stage:** 3 — Hardscape Tool
**Owner:** `angular-feature-engineer`
**Collaborators:** `renderer-engineer` (handle rendering, hit-testing), `scene-model-engineer` (transform commands), `test-engineer`
**Status:** Not started

## Goal

Select placed objects; move / rotate / scale / mirror them with on-canvas handles; multi-select via marquee. Every transform is an undoable Command.

## Spec reference

Plan Stage 3 F3.3.

## Dependencies

**Requires:** F0.3 (transform commands), F0.4 (renderer + hit-test), F3.1 (placed objects).
**Enables:** every later editing workflow (planting, layers, etc. all rely on the selection + transform pattern established here).

## Scope

**In:**

- Selection model: NgRx state `selection: ObjectId[]`. Single-select on click; Shift-click toggles; marquee-drag selects intersecting bounds; Escape clears.
- On-canvas handles rendered around selection:
  - Four corner scale handles.
  - One rotation handle above the bounding box.
  - Move via dragging the object body (no separate translate handle).
  - **Mirror/flip button** floating near the selection — toggles `flipX` on the selected object's transform (flips horizontally about the object's local center, no translation).
- Commands:
  - `TranslateObjects(ids, delta)` — drag-move.
  - `RotateObjects(ids, angleRadians, pivot)` — rotate handle.
  - `ScaleObjects(ids, factor, pivot)` — corner handle.
  - `FlipObject(id, axis: 'x' | 'y')`.
  - Each drag stroke is a CompositeCommand if it spans multiple frames — but the user sees one undo step.
- Keyboard: arrow keys nudge (1 px CSS = ~1 mm at 1× zoom, modifier for finer/coarser). R for rotation mode, S for scale (optional, document the choice).

**Out:**

- Non-uniform scale (separate x/y) — out for v1; uniform scale only.
- Snapping during transforms — F5.4.
- Smart guides (alignment indicators) — F5.3.

## Acceptance criteria

- [ ] Click selects, Shift-click adds/removes, Escape clears.
- [ ] Marquee selects every object whose AABB intersects the marquee rectangle.
- [ ] Drag moves the selection; rotation handle rotates; corner handle uniformly scales — all in real time.
- [ ] Mirror button flips the object horizontally about its center; the object does not translate visually.
- [ ] Every transform action is undoable as one step.
- [ ] Locked layers reject transform commands cleanly.
- [ ] Keyboard alternatives exist for every mouse action; handles are reachable via Tab when an object is selected.

## Testing

- **Unit:** flip math (verify `flipX` about local center is translation-free); rotation/scale around a pivot; marquee intersection.
- **Component:** simulated drag updates the transform; mirror button dispatches FlipObject.
- **E2E:** drag two rocks, mirror one, scale another, undo/redo chain, save/reopen identical — the Stage 3 milestone test.

## Notes

- **Flip ≠ rotate 180°.** Flipping a non-symmetric object visually mirrors it (a left-facing rock becomes right-facing). The renderer applies the `flipX`/`flipY` after positioning and scaling.
- **Handle hit-test must beat object hit-test.** When a handle is under the cursor, click-on-handle wins over click-on-object. Order layers in the hit-test accordingly.
- **Pivot for rotate/scale.** Default to the selection's bounding-box center; allow modifier-click on a handle to switch to "individual centers" later if needed.
