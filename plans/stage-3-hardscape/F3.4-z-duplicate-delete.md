# F3.4 — Z-position within a layer, duplicate, delete

**Stage:** 3 — Hardscape Tool
**Owner:** `scene-model-engineer`
**Collaborators:** `angular-feature-engineer`, `test-engineer`
**Status:** Not started

## Goal

Bring forward / send backward inside a layer, duplicate selected objects, and delete them — the boring-but-essential editor verbs.

## Spec reference

Plan Stage 3 F3.4.

## Dependencies

**Requires:** F0.3, F3.3 (selection).
**Enables:** Layer panel work in Stage 4.

## Scope

**In:**

- Commands:
  - `BringForward(ids)` / `SendBackward(ids)` — swap with the neighbor in the same layer's object list.
  - `BringToFront(ids)` / `SendToBack(ids)` — move to extremes within the layer.
  - `DuplicateObjects(ids, offset)` — clones with new UUIDs; transforms offset by a small `Vec3` (e.g. +20 mm x, +20 mm z) so the duplicate is visible.
  - `DeleteObjects(ids)`.
- Keyboard: Cmd/Ctrl+] forward, Cmd/Ctrl+[ backward, Cmd/Ctrl+Shift+] front, Cmd/Ctrl+Shift+[ back, Cmd/Ctrl+D duplicate, Delete/Backspace deletes.
- Context menu (right-click on selection) exposes the same actions.

**Out:**

- Cross-layer move — Stage 4 layers panel handles that.
- Group / ungroup — Stage 4 grouping covers it.

## Acceptance criteria

- [ ] Each command is invertible (property-tested as part of F0.3 invertibility coverage).
- [ ] DuplicateObjects assigns fresh UUIDs; original and copy do not share identity.
- [ ] Deleting a multi-select removes all objects in one undo step.
- [ ] Keyboard shortcuts work on both platforms.
- [ ] Locked layers reject these commands.

## Testing

- **Unit:** each command's apply/invert; UUID uniqueness on duplicate.
- **Component:** keyboard shortcuts dispatch the right action.
- **E2E:** duplicate → move → undo all → state matches pre-action.

## Notes

- **Duplicate behavior.** Plant or hardscape — they all duplicate the same way. Don't write per-type duplicates; the Command works on the common transform + catalogRef shape.
- **Delete vs hide.** Delete removes; layer-visibility (Stage 4) hides. Don't conflate them.
