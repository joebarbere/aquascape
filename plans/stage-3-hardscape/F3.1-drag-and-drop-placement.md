# F3.1 — Drag-and-drop hardscape placement

**Stage:** 3 — Hardscape Tool
**Owner:** `angular-feature-engineer`
**Collaborators:** `scene-model-engineer`, `renderer-engineer`, `test-engineer`
**Status:** Not started

## Goal

Drag rocks and driftwood from a side palette onto the canvas to place them in the scene. The first non-trivial editing flow.

## Spec reference

Plan Stage 3 F3.1.

## Dependencies

**Requires:** F0.3 (HardscapeObject + AddObject command), F0.4 (renderer draws objects), F3.5 (a catalog to drag from), F4.2 (a default "Hardscape" layer to drop into — or create one on-demand here).
**Enables:** F3.2/3.3/3.4 (everything else hardscape-related operates on placed objects).

## Scope

**In:**

- `features/hardscape-tool/` with a palette panel listing draggable hardscape entries from the catalog.
- HTML5 drag-and-drop or a custom pointer-based DnD (Angular CDK `DragDrop`). Choose CDK for accessibility and consistency.
- On drop onto the canvas:
  - Convert drop point (CSS px) → canvas px → world mm (via the active viewport).
  - Dispatch `AddObject` to insert a new `HardscapeObject` with the dragged catalog ref, a sensible default transform (translation = drop point, rotation = 0, scale = 1), and a default "front" layer assignment.
- Default layer: if no "Hardscape" layer exists, create one and add the object to it (via a CompositeCommand of `AddLayer` + `AddObject`).
- Drop ghost: while dragging, show a translucent ghost of the object at the cursor position.
- Keyboard alternative: select a palette entry with Enter, then arrow keys to position + Enter to place (a11y).

**Out:**

- Multiple-object selection / marquee — F3.3 or F3.4 includes selection.
- Multi-target drop targeting (e.g. "drop onto layer X") — keep it simple.

## Acceptance criteria

- [ ] Dragging from palette → canvas adds an object at the cursor location.
- [ ] The drop translates the cursor accurately to world mm — verified by snapshot at multiple zoom levels.
- [ ] Keyboard drop alternative works end-to-end.
- [ ] Drop ghost matches the placed object's bounding shape (not just a square).
- [ ] Undo removes the just-placed object cleanly.
- [ ] If no "Hardscape" layer existed, the CompositeCommand undoes both layer creation and object insertion in one step.

## Testing

- **Unit:** CSS-px → canvas-px → world-mm conversion.
- **Component:** simulated DnD inserts the right object.
- **E2E:** drag, drop, save, reopen — object persisted at the right position.

## Notes

- **Use Angular CDK DragDrop.** It handles touch + keyboard + screen reader announcements out of the box.
- **Drop should not require pixel-perfect aim.** A drop on the canvas anywhere places the object; the user repositions afterward with F3.3 handles.
- **Coordinate frames are subtle.** Document the conversion (cursor → canvas → world) clearly; this is the place coordinate bugs love to hide.
