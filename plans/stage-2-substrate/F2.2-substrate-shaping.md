# F2.2 — Substrate shaping

**Stage:** 2 — Substrate Tool
**Owner:** `angular-feature-engineer`
**Collaborators:** `scene-model-engineer`, `renderer-engineer`, `test-engineer`
**Status:** Not started

## Goal

Let the user sculpt the substrate's height profile with draggable control points, producing the slopes and terraces that define a planted tank's composition.

## Spec reference

Plan Stage 2 F2.2; substrate `profile` field (`Vec2[]`) in `aqua-document.ts`.

## Dependencies

**Requires:** F2.1 (a material to shape), F0.4 (render the profile).
**Enables:** F2.3 (bands inherit profiles), F4.x (plants reference substrate height when placed).

## Scope

**In:**

- The substrate `profile` is a list of `(x, y)` control points where `x ∈ [0, 1]` (normalized along tank width) and `y` is height in mm. Already in `aqua-document.ts`.
- Interpolation choice: **Catmull-Rom** spline through the control points (smooth, no overshoot at endpoints) — implement once in `domain/geometry`.
- Commands:
  - `AddProfilePoint(p, atIndex)`
  - `MoveProfilePoint(index, newP)`
  - `RemoveProfilePoint(index)` (with a minimum of 2 points to keep the profile valid).
- Renderer extension: draw the substrate as the area between the profile curve and the tank floor, filled with the material's pattern.
- UI in `features/substrate-tool/`:
  - Control-point handles (draggable circles) along the profile.
  - Click on the curve to add a point; drag to move; click handle + Delete to remove.
  - Snap to 10 mm grid optional (cm/in display toggle respected).
  - Undo per edit (each drag is one Command, or a CompositeCommand for a drag stroke).

**Out:**

- Per-region profiles — F2.3 introduces bands with their own profiles.
- 3D substrate mesh extrusion — Stage 10.

## Acceptance criteria

- [ ] Curve passes through every control point.
- [ ] Profile renders correctly clipped to the tank width and material region.
- [ ] Each drag is undoable; the entire drag is one user-visible undo step.
- [ ] Profile is bounded: cannot exceed tank height; cannot go negative.
- [ ] Profile control points are keyboard-accessible (arrow keys nudge selected point; Tab cycles points).

## Testing

- **Unit:** Catmull-Rom interpolation math; clamping; point insertion order.
- **Component:** drag a point emits the right command; click-on-curve inserts at the right index.
- **E2E:** sculpt a slope → save → reopen → profile preserved (the Stage 2 milestone test).

## Notes

- **Catmull-Rom vs linear.** Linear is simpler but produces unrealistic kinked substrate; Catmull-Rom is the sweet spot between smoothness and predictability. Avoid cubic-bezier handles (too many DoF for a substrate profile).
- **Performance.** The profile evaluation is per-render; cache the polyline approximation between point changes if profiling shows it's hot.
- **Mobile / touch.** Touch handles must be large enough to grab; respect `pointercoarse` media query for sizing.
