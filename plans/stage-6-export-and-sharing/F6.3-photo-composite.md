# F6.3 — Composite onto real tank photo

**Stage:** 6 — Export & Sharing
**Owner:** `angular-feature-engineer`
**Collaborators:** `renderer-engineer`, `aqua-document-guardian`, `test-engineer`
**Status:** Not started

## Goal

Import a real photograph of a tank (empty or in-progress) as a backdrop, position the design over it, and export the composite. A GIMP-style capability made native.

## Spec reference

Plan Stage 6 F6.3.

## Dependencies

**Requires:** F0.4 (renderer), F1.3 (asset storage), F1.4 (file IO).
**Enables:** Photorealism-adjacent previewing without AI.

## Scope

**In:**

- "Import backdrop photo" action: choose an image file → stored as an asset inside the `.aqua` ZIP container under `assets/` → referenced from `tank.style.background = { kind: 'image', assetRef: 'assets/photo.jpg' }`.
- Calibration: 2-point calibration UI where the user clicks two points on the photo and enters the real-world distance, so the design is scaled to the photo's perspective.
- Renderer extension: when `background.kind === 'image'`, render the asset behind everything, scaled per the calibration.
- Composite export: F6.1's export pipeline picks up the backdrop automatically.

**Out:**

- Perspective correction / homography — out for v1; assume the photo is roughly front-on.
- Multi-photo backdrops — single backdrop only.
- Cropping the photo in-app — out of scope; users crop before importing.

## Acceptance criteria

- [ ] Backdrop photo imports, stores as an asset in the `.aqua` ZIP, and renders behind the scene.
- [ ] Calibration scales the scene to match real-world dimensions in the photo.
- [ ] Removing the backdrop reverts to color/gradient.
- [ ] Export composite produces a single image including the backdrop.

## Testing

- **Unit:** calibration math (2-point distance → scale factor).
- **Component:** asset attachment and removal.
- **E2E:** import → calibrate → place an object → export → reopen — backdrop preserved.

## Notes

- **Asset size discipline.** Large backdrops bloat documents. Surface the file size on import and offer a downscale option (e.g. cap at 2048 px on the long edge).
- **Coordinate with `aqua-document-guardian`** on any schema additions for backdrop references; the `background.kind: 'image'` shape already exists in v1.
