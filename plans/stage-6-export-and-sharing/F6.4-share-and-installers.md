# F6.4 — Share `.aqua` + PWA install + desktop installers

**Stage:** 6 — Export & Sharing
**Owner:** `electron-platform-engineer` (installers), `angular-feature-engineer` (PWA), `test-engineer`
**Status:** Not started

## Goal

Ship distributable artifacts: a PWA-installable web build and packaged installers for Linux / macOS / Windows.

## Spec reference

Plan Stage 6 F6.4.

## Dependencies

**Requires:** Stages 0–5 complete enough that an installable v1.0 is meaningful.
**Enables:** v1.0 release.

## Scope

**In, PWA (`apps/web/`):**

- `manifest.webmanifest` with icons (192/512), name, short_name, description, start_url, scope, theme_color, background_color.
- Service worker for offline app-shell: caches the built assets so a previously-loaded session works offline (documents are still local-only).
- Lighthouse PWA score ≥90 in CI.

**In, Electron installers (`apps/desktop/`):**

- `electron-builder` (or equivalent) producing:
  - `.dmg` for macOS (Universal: x64 + arm64) — code-signed + notarized.
  - `.exe` (NSIS) for Windows — code-signed.
  - `.AppImage` and `.deb` for Linux.
- Auto-updater configured (signed releases only). Channel: `stable`.
- Crash reporter — opt-in only, fully disable-able (FOSS expectation per plan §5).

**In, sharing UX:**

- "Export `.aqua`…" action (web): downloads the file directly.
- "Reveal in Finder/Explorer" (Electron): exposes the saved doc to the user's file manager.

**Out:**

- Auto-update on Linux — typically not packaged; document the choice.
- Multi-channel releases (beta, nightly) — post-v1.

## Acceptance criteria

- [ ] PWA installable in Chrome/Edge; Lighthouse PWA ≥90.
- [ ] Service worker caches the app shell; offline reload works.
- [ ] Installer artifacts produced by CI for all three desktop platforms.
- [ ] macOS build is notarized and opens without Gatekeeper warning.
- [ ] Windows build is signed and opens without SmartScreen warning (or the warning is benign — first-run reputation takes time).
- [ ] Auto-updater roundtrip from version N to N+1 works in a staging channel.
- [ ] Crash reporter is opt-in with a clear consent dialog on first run; disabling it stops all reports immediately.

## Testing

- **Unit:** opt-in state honored.
- **E2E:** smoke test each installer on a fresh VM image.

## Notes

- **Signing certs** must be stored as CI secrets, not in the repo. Document the bootstrap process.
- **App identifier (bundle ID)** must be locked in before the first signed release — changing it later breaks user update paths.
- **License.** Confirm OSS license (per project pitch as "FOSS"). MIT or Apache-2.0 are good defaults. Pick before v1 release.
