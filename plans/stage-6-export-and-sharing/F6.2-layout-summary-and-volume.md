# F6.2 — Layout summary + volume / parts list

**Stage:** 6 — Export & Sharing
**Owner:** `angular-feature-engineer`
**Collaborators:** `catalog-engineer` (read substrate displacement coefficients), `test-engineer`
**Status:** Not started

## Goal

Generate a layout summary document: tank volume, substrate displacement, plant list, hardscape list, suggested parameters. Exportable as PDF / Markdown / HTML.

## Spec reference

Plan Stage 6 F6.2.

## Dependencies

**Requires:** F2.x (substrate), F3.x (hardscape), F4.x (plants).
**Enables:** Stage 7 setup sheet builds on this.

## Scope

**In:**

- Pure aggregator in `domain/document` (or a new `domain/summary`):
  ```ts
  function summarize(scene: Scene, catalog: Catalog[]): LayoutSummary;
  interface LayoutSummary {
    tank: { dimensionsMm: Vec3; volumeL: number; volumeGal: number };
    substrate: {
      regions: { material: string; depthRangeMm: [number, number]; estimatedLiters: number }[];
      totalDisplacementL: number;
    };
    plants: {
      id: string;
      name: string;
      zone: string;
      count: number;
      care: { light: string; co2: string; difficulty: string };
    }[];
    hardscape: { id: string; name: string; kind: string; count: number }[];
    suggestedParams: {
      lightingHours?: string;
      co2BubblesPerSecond?: string;
      tempC?: string;
      pH?: string;
    };
  }
  ```
- Volume calc: tank volume - substrate displacement (using each material's `displacementCoefficient` from F2.1).
- L ↔ gal conversion using exact `0.264172` factor.
- `features/export/` UI: "Export summary" → user picks format → renders Markdown/HTML/PDF.

**Out:**

- Live recommendations (sales pitches for fertilizers etc.) — out of scope.
- Localization of units — defer.

## Acceptance criteria

- [ ] Volume math is correct for known fixtures (e.g. 360×220×220 tank with no substrate = 17.4 L exactly).
- [ ] Displacement reduces volume by the documented factor per material.
- [ ] Plant counts aggregate correctly across layers + groups.
- [ ] Markdown / HTML / PDF outputs are well-formed.

## Testing

- **Unit:** volume math; aggregation; conversion factors.
- **Snapshot:** Markdown output for a known fixture scene matches a checked-in reference.
- **E2E:** generate summary, save, open the file.

## Notes

- **PDF generation.** Use a lightweight library (e.g. `pdf-lib` or `jspdf`) or render HTML to PDF via a hidden Electron BrowserWindow. Either works; pick one and document.
- **Suggested params are heuristic.** Derive from plant care metadata (e.g. if any plant is "high light", suggest 8+ hrs; if "CO2 required", suggest 2-3 bps). Mark as estimates.
