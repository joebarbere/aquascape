# F6.1 — Image export

**Stage:** 6 — Export & Sharing
**Owner:** `angular-feature-engineer`
**Collaborators:** `renderer-engineer`, `electron-platform-engineer`, `test-engineer`
**Status:** Not started

## Goal

Export the current view as a PNG (and JPEG) at user-chosen resolution. Web and Electron produce **identical pixels** at the same size.

## Spec reference

Plan Stage 6 F6.1.

## Dependencies

**Requires:** F0.4 (renderer must support offscreen attach), F0.5 (RenderExportService), F1.4 (file IO patterns).
**Enables:** F6.2 (export summary attaches as metadata), F6.3 (composite onto a photo).

## Scope

**In:**

- `features/export/` panel: format (PNG / JPEG), resolution presets (1920×1080, 4K, exact tank dimensions × user-chosen ppi), background (transparent / solid color), overlays included? (off by default — they're non-printing per F5.3).
- Renderer change: `Canvas2DRenderer` accepts an offscreen `OffscreenCanvas` or a constructed `HTMLCanvasElement` as its `RenderSurface`. Same rendering path; same outputs.
- Export pipeline:
  - Create offscreen canvas at requested dimensions.
  - Attach a renderer.
  - Render the active scene at a viewport that fits the tank (with user-controlled padding).
  - `canvas.convertToBlob()` → bytes.
  - Hand bytes to `RenderExportService.exportPng` for the user to save.
- Determinism check: web and desktop produce byte-identical bytes for the same input (verified in CI as part of plan §3 — F6.1 establishes this gate).

**Out:**

- SVG / PDF export — out for v1.
- Video export (timelapse over growth weeks) — defer.
- High-DPI print preflight — defer.

## Acceptance criteria

- [ ] PNG export at requested resolution produces a valid image file.
- [ ] Overlays excluded by default; opting in includes them (rendered correctly at export resolution).
- [ ] Web and Electron produce identical PNG bytes at the same input.
- [ ] No regression in interactive rendering (offscreen path doesn't break the on-screen path).
- [ ] Export progress is announced for large dimensions (>4K).

## Testing

- **Unit:** dimension calculation; viewport-fit math.
- **Integration:** snapshot test compares export bytes to a checked-in PNG (tolerance 0 since the renderer is deterministic).
- **E2E:** export PNG → file saved to chosen location; bytes match between web and Electron for the same scene.

## Notes

- **Offscreen rendering.** Use `OffscreenCanvas` where supported; fall back to a hidden `HTMLCanvasElement`. Either path must produce identical bytes.
- **JPEG color drift** — JPEG is lossy; the determinism gate applies to PNG. Document this.
- **The renderer is the same.** Don't write a "headless renderer" — the export pipeline must use `renderer-2d` (and Stage 10's `renderer-3d`) directly. Any divergence is a bug.
