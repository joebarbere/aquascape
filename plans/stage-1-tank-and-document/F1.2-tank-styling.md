# F1.2 — Tank styling

**Stage:** 1 — Tank Setup & Document Lifecycle
**Owner:** `angular-feature-engineer`
**Collaborators:** `renderer-engineer` (glass / water tint render), `scene-model-engineer` (style command), `test-engineer`
**Status:** Not started

## Goal

Let the user pick visual styling for the tank: frame style (rimless / black-rim / wood-cabinet), water tint, and background color/image. Style fields persist in the document.

## Spec reference

Plan Stage 1 F1.2; tank `style` object in `aqua-document.ts`.

## Dependencies

**Requires:** F1.1 (tank exists to style), F0.4 (renderer to consume style fields).
**Enables:** richer rendered tank in every subsequent feature.

## Scope

**In:**

- `features/tank-setup/` styling subpanel:
  - Frame style picker: `rimless`, `black-rim`, `cabinet-light`, `cabinet-dark` (extensible later).
  - Water tint picker: hex color with sensible presets (clear, slight green, tannin amber).
  - Background picker: solid color, gradient (two-stop), or future "image" (deferred to F6.3 — show as disabled with a tooltip).
- `SetTankStyle` command in `domain/scene-model`.
- `renderer-2d` extensions:
  - Draw glass frame edges per style.
  - Draw water tint as a semi-transparent overlay inside the tank rectangle.
  - Draw background behind the tank.
- Style fields serialize to the existing tank `style` object (per `aqua-document.ts`) — no schema change required if v1 already covers them; if not, coordinate with `aqua-document-guardian` for an additive field.

**Out:**

- Background photo import — F6.3.
- 3D glass thickness/refraction rendering — Stage 10.

## Acceptance criteria

- [ ] All style fields persist and round-trip via `.aqua`.
- [ ] Renderer reflects style choices accurately and in real time.
- [ ] `SetTankStyle` is invertible.
- [ ] Default style on a new document is "rimless / clear water / neutral dark background" — easy on the eyes, neutral for any aquascape style.
- [ ] Style picker is keyboard-navigable; color inputs have ARIA labels and announce their hex values.

## Testing

- **Unit:** command invertibility; default style constant.
- **Component:** style changes dispatch the right command.
- **E2E:** change style, save (F1.4), reopen — style preserved; renderer matches before/after.

## Notes

- **Frame styles as catalog data?** The plan implies tank style is per-document, not per-tank-catalog-entry. Treat it as an inherent property of the placed tank, not a catalog field. The tank catalog can suggest a default style.
- **Color picker.** Use a well-tested library or Angular CDK overlay primitive; rolling your own color picker is a tar-pit. Confirm it supports hex input and is accessible (screen-reader and keyboard).
