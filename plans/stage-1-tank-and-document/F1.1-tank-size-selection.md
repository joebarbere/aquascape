# F1.1 — Tank size selection

**Stage:** 1 — Tank Setup & Document Lifecycle
**Owner:** `angular-feature-engineer`
**Collaborators:** `scene-model-engineer` (`SetTankDimensions` command), `catalog-engineer` (tank presets), `test-engineer`
**Status:** Not started

## Goal

Let the user pick a tank: standard presets (ADA Mini-M and common sizes) or a custom W×H×D, with a cm/in display toggle. Selection drives a `SetTankDimensions` command and updates the scene.

## Spec reference

Plan Stage 1 F1.1; tank entity in `aqua-document.ts`.

## Dependencies

**Requires:** F0.3 (Scene/tank model), F0.4 (renderer to update), F0.6 (app shell), and at least a thin catalog stub from F2.4 — or inline tank presets in this feature and migrate later.
**Enables:** F1.2 (styling acts on the selected tank), F1.3 (tank persists), F1.6 (NgRx tracks dirty state).

## Scope

**In:**

- `features/tank-setup/` Angular standalone component(s):
  - Preset list (radio group / dropdown): ADA Mini-M, Mini-S, 60-P, 90-P, 120-P, plus a generic "Standard 10 / 20 / 40 gal" set. Source of truth: a small catalog manifest (recommended) or inline constants temporarily.
  - Custom dimensions form (W × H × D) with cm/in unit toggle.
  - Validation: min 100 mm, max 3000 mm per dimension; integer mm after unit conversion; aspect-ratio sanity warning (not error) outside ~0.3–4.0 W/H.
- A `SetTankDimensions` command in `domain/scene-model` (this feature's reason to coordinate with `scene-model-engineer`):
  - Captures previous dimensions in `invert`.
  - Clamps existing placed objects per a documented rule: positions clamp inside the new bounding box; nothing is silently deleted.
- cm/in toggle is **display-only**; storage and the command payload are mm.
- Wire the component to dispatch the command via NgRx (the action/reducer/effect lives in `state/`).

**Out:**

- Glass / water tint / background styling — F1.2.
- Tank persistence to `.aqua` — F1.3 owns the format work; this feature just feeds it.

## Acceptance criteria

- [ ] All preset dimensions match published manufacturer specs (verify against ADA's published Mini-M = 360×220×220 mm, etc.).
- [ ] Custom dimensions validate and reject out-of-range values with clear errors.
- [ ] cm/in toggle round-trips losslessly: cm → in → cm ≡ original.
- [ ] Picking a smaller tank with placed objects clamps positions; a unit test exercises the documented clamping rule and confirms no object is deleted.
- [ ] `SetTankDimensions` is invertible (property-tested as part of F0.3's invertibility coverage).
- [ ] Keyboard navigation through the form is complete; ARIA labels on every input; `aria-describedby` on validation errors.

## Testing

- **Unit:** preset table values; conversion math; clamping rule.
- **Component:** Angular Testing Library — preset selection emits the right command; custom form validates; unit toggle works.
- **E2E:** Playwright in web + Electron — pick a preset, switch to in, switch to custom, save (covered by F1.4) — confirm the tank rect resizes.

## Notes

- **Sourcing preset data.** Either ship a built-in tank catalog manifest (preferred — F2.4 hooks into this anyway) or keep an inline constants file as a stop-gap. If inline, leave a TODO referencing the catalog migration.
- **Aspect-ratio warning vs error.** Warnings let advanced users build weird shapes (e.g. shallow scapes); silently allowing them is friendlier than blocking. Block only physically nonsensical inputs (≤0, NaN, beyond min/max).
- **Don't bake unit display into the document.** The document stores mm. The UI toggle is a user preference, persisted via `StorageService` (covered later).
